# 技术笔记

构建、设备、排错。

## 1. 构建流程（无 Gradle）

```
aapt package  →  javac  →  d8  →  aapt add classes.dex  →  zipalign  →  apksigner
```

- minSdkVersion / targetSdkVersion = 19，不能用 AndroidX
- Java 源码级别 `-source 1.7 -target 1.7`
- API < 24 必须用 v1 签名
- 资源 id 由 aapt 生成到 `build/gen`

`scripts/build.sh` 已封装，产物在 `build/adplayer-<版本>.apk`。
工具链与签名都通过环境变量传入，见 README「配置」一节。

## 2. 参考设备

以下是在开发机上实测过的机型参数，仅作兼容性参考，不代表程序绑定该型号：

| 项 | 值 |
|---|---|
| 芯片 | RK3128（4×Cortex-A7，Mali-400MP2） |
| 系统 | Android 4.4.4 / API 19 |
| 分辨率 | 1920×1080 @160dpi |
| 内存 | 约 1 GB |
| Root | 有，SELinux disabled |
| 调试连接 | Wi-Fi adb（`adb connect <设备IP>:5555`） |

### 已知网络问题

老机型 Wi-Fi 不稳：adb 会周期性 `device offline`，有时 ping 不通但 8080 还活着。
处理：`adb disconnect && adb connect` 重试；不行就断电重启。

## 3. 厂商守护进程（可选）

- 出厂自带，作用是不断把被守护的包拉回前台（不同厂商的包名不同，开发机上为 `com.guardian`）
- 配置一般在 `/data/data/<包名>/shared_prefs/*.xml`
  - 守护包名、检查间隔（毫秒）、开关等字段
- 改完要重启守护进程：

```bash
adb shell su -c "am force-stop <守护进程包名>"
adb shell su -c "am startservice -n <守护进程包名>/.service.GuardianService"
```

App 内由 `Root.applyGuardianInterval()` 完成；如果你的机型没有这个守护进程，
把设置页的「守护间隔」留空即可，不影响其它功能。

## 4. 定时开关机

- RTC 芯片（开发机上为 `rtc-pcf8563`）
- 写闹钟：`echo <epoch秒> > /sys/class/rtc/rtc0/wakealarm`
- 关机：`reboot -p`
- 芯片时间用 UTC，设备显示本地时区

## 5. 手机上传服务（内置 HTTP，端口 8080）

| 接口 | 说明 |
|---|---|
| `GET /` | 管理页面 |
| `GET /list` | 素材 JSON |
| `GET /thumb?path=` | 缩略图（图片解码 / 视频抽帧，磁盘缓存） |
| `GET /view?path=` | 原图 |
| `POST /upload?name=&type=&size=` | 上传（原始字节流，非 multipart） |
| `POST /delete?path=a&path=b` | 单删 / 批量删 |
| `POST /organize` | 散落文件归位 |
| `POST /transcode?path=` | 单个转码 |
| `POST /transcode_all` | 批量转码 |
| `GET /jobs` | 转码状态 |
| `GET /probe?path=` | 探测可解码性 |
| `GET /space` | 剩余空间 |

服务**没有鉴权**，只应在可信局域网内使用。

## 6. 自动转码

- 需要一份支持 libx264 的 **armhf 静态 ffmpeg**，推到设备 `/data/local/tmp/ffmpeg` 并 `chmod 755`
- 仓库不附带二进制（体积与许可证原因），可以自行编译或使用发行版提供的静态构建
- 触发条件：上传的视频非 avc 或 > 1920×1080
- 命令：

```
ffmpeg -y -i in.mp4 -c:v libx264 -preset ultrafast -crf 26 \
       -vf "scale='min(1280,iw)':-2" -c:a aac -b:a 96k \
       -movflags +faststart out.mp4
```

- 速度约为实时的 1/3；成功后替换原文件

## 7. 常见问题

| 现象 | 原因 / 处理 |
|---|---|
| 页面打不开 | 手机与设备不同 Wi-Fi，或播放器不在前台 |
| 上传后不播放 | 页面显示 ⚠ 无法播放 → 点「批量转码」 |
| 提示「无法播放：xxx」 | 编码不支持或文件损坏 |
| adb device offline | Wi-Fi 不稳，重连或断电重启 |
| 设置页焦点乱跳 | 容器不要加 focusable，控件用 Button |
| 转码一直排队 | 设备上没有 `/data/local/tmp/ffmpeg`，或没有执行权限 |
