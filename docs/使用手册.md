# 使用手册

面向使用者：怎么装、怎么按键、素材放哪里、手机怎么传。

## 一、安装

```bash
export DEVICE_IP=<设备局域网IP>
./scripts/install.sh
```

也可以用构建出来的 `build/adplayer-<版本>.apk` 拷到 U 盘安装，或从 GitHub Releases 下载预编译包（发布时提供）。
部分广告机固件在安装 APK 后会自动重启一次（约 20–30 秒 Wi-Fi 断开再连回），属固件行为，不是故障。

## 二、遥控器按键

| 按键 | 功能 |
|---|---|
| **MENU 键** | 打开设置页（推荐） |
| **长按 OK 键 1.2 秒** | 打开设置页 |
| **长按屏幕 1.2 秒**（触摸屏） | 打开设置页 |
| **右键 / 下一曲 / 频道+** | 播放下一个 |
| **左键 / 上一曲 / 频道-** | 播放上一个 |
| **OK / 确定 / 播放暂停键** | 暂停 / 继续 |
| **↑** | 打开底部快捷抽屉（列表循环 / 单文件循环 / 完整设置） |
| **↓** | 一键切换列表循环 / 单文件循环 |
| **返回键** | 屏幕提示「按 MENU 键进入设置」 |

操作时屏幕顶部会出现「下一个 / 已暂停 / 继续播放」的小提示。

## 三、设置页

| 项目 | 说明 |
|---|---|
| 屏幕布局 | 单屏全屏 / 左右分屏 / 上下分屏 / 四宫格 |
| 各区域素材文件夹 | 只显示当前布局需要的区域数量：单屏 1 个、分屏 2 个、四宫格 4 个 |
| 每张图片停留秒数 | 默认 5 秒 |
| 随机播放顺序 | 打乱文件名顺序 |
| 视频静音 | 默认开（广告机一般不发声） |
| 开机自动启动 | 默认开 |
| 循环模式 | 列表循环 / 单文件循环 |
| 每天定时重启 | 格式 `HH:mm`，例如 `03:00`，留空不重启 |
| 每天定时关机 / 开机 | 见第六节 |
| 每天熄屏 / 亮屏 | 格式 `HH:mm`，到点自动关屏 / 亮屏 |
| 守护间隔 | 守护进程把播放器拉回前台的检查周期，默认 300 秒 |
| 设置页密码 | 4 位数字，留空不设密码；`0000` 等同于不设 |

所有设置项都能纯用遥控器完成：方向键移动 / 加减，OK 确认，数字键可以直接键入数字。

## 四、素材怎么放

- 默认目录 `/mnt/sdcard/广告素材`，可以建子文件夹（最多扫 3 层）
- 视频：mp4 / 3gp / mkv / avi / webm / mov / ts / m4v / flv / wmv / mpg / mpeg
- 图片：jpg / jpeg / png / bmp / webp / gif
- 排序：按文件名自然排序（1、2、10 不会排成 1、10、2）

推荐格式：**MP4 容器 + H.264 视频 + AAC 音频**，分辨率 ≤ 1920×1080，帧率 ≤ 30fps。
老芯片（RK3128）只稳定支持这一种组合；H.265 / HEVC、10bit、4K 播放不了，需要转码。

## 五、手机网页管理素材

播放器启动后会在局域网开一个网页服务，设置页顶部会显示地址：

```
http://<设备IP>:8080
```

手机连同一个 Wi-Fi，浏览器打开这个地址即可：

- 一次选多个视频 / 图片（直接调手机相册）
- 每个文件独立进度条、实时速度、已传 / 总大小
- 缩略图网格，可单选 / 全选 / 批量删除（两步确认，防误删）
- 上传后自动探测可播放性：✓ 可播放 / ⚠ 无法播放
- 上传时自动分类：图片进 `照片/`，视频进 `视频/`
- 「自动整理」把根目录散落的文件归位
- 显示剩余空间

### 自动转码

上传的视频如果不是 H.264 或分辨率超过 1080p，设备会自动调用 ffmpeg 转码为
H.264 Baseline + AAC（宽度 ≤ 1280，faststart），转码完成后替换原文件。
页面每 3 秒刷新进度：排队中 → 正在转码 N% → 已转成 H.264。
也可以点「批量转码」把已有视频全部过一遍。

转码速度约为实时的 1/3（5 分钟的片子约 1.5–2 分钟），期间设备会变慢，播放可能卡顿几秒。

## 六、定时开关机

| 设置项 | 实际动作 |
|---|---|
| 每天定时开机（整机开机） | 写 RTC 闹钟 `/sys/class/rtc/rtc0/wakealarm` |
| 每天定时关机（整机断电） | `su -c reboot -p` |
| 每天定时重启 | `su -c reboot` |
| 软件熄屏时间（不关机） | `input keyevent 26`，只关屏幕，机器还在运行 |
| 软件亮屏时间 | `input keyevent 26`，再按一次亮屏 |

关机流程：到点 → 先算出下一次开机时间 → 写进 RTC 闹钟 → 再执行 `reboot -p`。

> 从「完全断电」状态能否被 RTC 唤醒，取决于主板是否把 RTC 中断接到电源管理芯片，
> 不同批次机型差异很大，需要自己实测。

## 七、开机自启与守护进程

很多广告机出厂自带一个「守护进程」，作用是不断把某个包名拉回前台。
把它的守护包名改成播放器的包名，就能实现开机自动拉起、被关掉自动拉回来、按 Home 也回到播放器。

App 设置页里的「守护间隔」会自动改写守护进程的配置并重启它，具体路径与包名见
[docs/技术笔记.md](技术笔记.md#3-厂商守护进程可选)。

## 八、常见问题

| 现象 | 原因 / 处理 |
|---|---|
| 手机页面打不开 | 手机与设备不在同一 Wi-Fi，或播放器不在前台 |
| 上传后不播放 | 页面显示 ⚠ 无法播放 → 点「批量转码」 |
| 提示「无法播放：xxx」 | 编码不支持或文件损坏 |
| adb device offline | 设备 Wi-Fi 不稳，`adb disconnect && adb connect` 重试 |
| 设置页焦点乱跳 | 容器不要加 focusable，控件用 Button |
| 恢复出厂后不能自动转码 | ffmpeg 放在 `/data/local/tmp`，会随恢复出厂丢失，重新推一次 |
